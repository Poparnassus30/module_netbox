                OK 👌 là on a la cause exacte : NetBox démarre, fait les migrations… puis crashe à cause d’un paramètre manquant lié aux API tokens v2.
                Dans tes logs :
                Warning au début : API_TOKEN_PEPPERS is not defined. v2 API tokens cannot be used.
                Puis crash fatal : ValueError: API_TOKEN_PEPPERS is not defined
                Et le conteneur sort avec code 1 → donc aucun port 8000 n’écoute.
                👉 Conclusion : ton image NetBox essaie de créer/traiter des tokens v2, mais tu n’as pas défini API_TOKEN_PEPPERS. Il faut le définir (c’est un secret, comme SECRET_KEY).
